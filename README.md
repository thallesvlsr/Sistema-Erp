# Sistema-Erp
ERP de Controle de Estoque desenvolvido em Python, com gerenciamento de produtos, fornecedores e movimentações de estoque. O projeto implementa estruturas de dados e algoritmos, incluindo Lista, Pilha, Fila de Prioridade, Árvore AVL, Busca Binária, Insertion Sort e Merge Sort, aplicados à organização, consulta, ordenação e reposição de produtos.
