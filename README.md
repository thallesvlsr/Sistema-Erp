ERP de Controle de Estoque

Sistema ERP de Controle de Estoque desenvolvido em Python, com o objetivo de gerenciar produtos, fornecedores e movimentações de estoque, aplicando conceitos de Algoritmos e Estruturas de Dados.
O projeto foi desenvolvido como parte de um trabalho acadêmico, com foco na implementação manual de estruturas de dados e algoritmos para solucionar problemas reais de gerenciamento de estoque.
- Cadastro e gerenciamento de produtos.
- Cadastro e gerenciamento de fornecedores.
- Controle de entrada e saída de produtos.
- Histórico de movimentações de estoque.
- Desfazer movimentações.
- Identificação de produtos com estoque baixo ou zerado.
- Sistema de reposição de estoque.
- Relatórios e consultas de produtos.
- Busca de produtos e fornecedores.
- Ordenação de produtos por diferentes critérios.
O projeto utiliza implementações próprias de estruturas de dados e algoritmos:
| Estrutura / Algoritmo | Aplicação |
|---|---|
| Lista | Organização de fornecedores |
| Pilha | Histórico e desfazer movimentações |
| Fila de Prioridade | Priorização de produtos para reposição |
| Árvore AVL | Busca e organização de produtos |
| Busca Binária | Pesquisa de fornecedores |
| Insertion Sort | Ordenação de produtos |
| Merge Sort | Ordenação de produtos |
As estruturas e os algoritmos foram implementados manualmente, sem depender de bibliotecas prontas para suas operações principais.
- Python 3
- Estruturas de Dados
- Algoritmos de Ordenação
- Algoritmos de Busca
- Programação Orientada a Objetos
O sistema está organizado em módulos para separar as responsabilidades:
- `modelos/` – Classes de produtos, fornecedores e movimentações.
- `servicos/` – Regras de negócio e gerenciamento do sistema.
- `estruturas/` – Implementações das estruturas de dados.
- `algoritmos/` – Algoritmos de busca e ordenação.
- `main.py` – Arquivo principal e menu de interação.

Objetivo acadêmico
Aplicar na prática os conceitos estudados em Algoritmos e Estruturas de Dados, desenvolvendo um sistema funcional que utiliza estruturas implementadas manualmente para gerenciamento, organização, pesquisa e controle de estoque.
